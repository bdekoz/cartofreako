# Setouchi H3r5 — manual WordPress update

Unzip this folder, then open [START-HERE.html](START-HERE.html) in your browser. Keep it open beside the WordPress page editor. Use your normal WordPress login; no application password, command line, or plugin installation is required for these steps.

The guide covers uploading the files, placing the World and Japan grids after the three existing lists, adding the Hamonshū row, and linking larger images and source legends. It includes copy-ready captions and alternative text for all thirteen figures.

- `uploads/`: the 36 web files, numbered in placement order.
- [preview.html](preview.html): an offline layout and image reference.
- [CAPTIONS-AND-ALT-TEXT.txt](CAPTIONS-AND-ALT-TEXT.txt): plain-text copy sheet.
- [UPLOAD-CHECKLIST.csv](UPLOAD-CHECKLIST.csv): filename/role mapping and an optional URL worksheet.
- [manifest.json](manifest.json): H3r5 selection, source hashes, and media inventory.
- [validation.json](validation.json) and [SHA256SUMS](SHA256SUMS): package checks.

Only the files in `uploads/` go into the WordPress Media Library. The guide, preview, and worksheets are local references. The package contains 13 gallery cards, 13 larger images, and 10 source-legend PDFs. All media bytes match the validated selected edition.

The much larger 300 dpi print masters remain in the repository’s selected H3r5 print edition; they are not needed for this website update. The website and its media library have not been changed by creating this package.
