Update the Setouchi page in WordPress

Unzip the package and open this file in your browser. Keep it beside the WordPress editor. The package contains 36 upload files, 11.0 MB total: thirteen gallery images, thirteen larger images, and ten legend PDFs.

Use your normal WordPress login. These instructions use the visual block editor and require no application password, terminal commands, or plugin installation.

Open the existing page editor · View the destination page · Open the offline gallery reference

1. Upload the web files

  1. In the WordPress dashboard, open Media → Add New. Select the thirty-six files inside this package’s uploads folder. Upload the files themselves; the ZIP and this guide stay on your computer.
  2. Wait for the uploads to finish. Names begin with placement numbers 01–13. Each map has -card, -detail, and -legend files. Hamonshū has a card and a detail.
  3. Keep Media → Library open in a second tab. Open each detail image or PDF and use Copy URL to clipboard when a link is needed. WordPress media instructions.

The optional upload worksheet lists every file, its role, and a blank column for its uploaded URL. Get URLs from WordPress; filenames alone are not links.

Keep the larger map details: WordPress may create a smaller -scaled version during upload. For the supplied 3840-pixel map details, use the Original image link in the attachment details when it appears: open that link and copy its address for the image’s detail link. Otherwise use the file URL. WordPress image scaling · Original-image control.

If the gallery already exists and you only need the r5 change: upload the twelve files numbered 03, 04, 08, and 09. Replace those four image blocks, captions, alt text, detail links, and legend links. Keep the existing gallery in its current position.

2. Locate the insertion point

  1. Open Pages → All Pages and edit the existing Setouchi 2028 page, or use the editor link above. Confirm its permalink is /futures/setouchi-2028/.
  2. Open Document Overview → List View. Find the heading “Two atlases, one shared table”. Use its three-dot menu’s Add before control to insert the gallery immediately before it, after the three existing lists. WordPress List View instructions.
  3. Add a Group block. In its Advanced → HTML anchor field, enter setouchi-futures-visuals. Put all the new gallery content inside this Group. If that Group already exists, edit its contents instead of inserting a second one. WordPress Group instructions.

Keep the existing lists, following heading, and surrounding page text in place. Retain the theme’s typography; the Star-X reference applies to web typography and spacing. The map artwork already uses the approved modified Setouchi AuthaGraph composition.

3. Build the two grids and Hamonshū row

Add the three section headings as Heading level 3. Use Columns blocks with equal widths for the rows below. Keep Stack on mobile enabled. The observer image sits directly in the Group, below its two rows, and spans the gallery’s content width. WordPress Columns instructions.

Mori Yūzan, Hamonshū (1903). Three water-pattern details, segmented for the Izzi review collection.

4. Add each image, caption, and link

  1. Inside its column or full-width position, add an Image block. Choose Media Library and select that figure’s -card file. Use the full 1280-pixel card, with automatic height and enough width to fill its column.
  2. Paste the supplied alt text into the Image block’s alternative-text field. Paste the two-line caption below the image; bold its title line. Use a soft line break between the title and description if the editor needs one.
  3. Use the Image block’s Link control to paste the uploaded URL of its matching -detail file. This opens the larger view, including the full Japan sheet.
  4. For maps, add Legend & sources as another caption line, select that text, and link it to the corresponding uploaded -legend.pdf URL. For Hamonshū, use Book review and the review URL supplied below.

WordPress Image block instructions · Link controls.

Framing: keep complete images visible. Use Contain when setting an aspect ratio. The reference uses 44:19.052559 frames for maps; if your editor has no custom-ratio control, use Original for the map cards. The three Japan crops will then be taller than the full-sheet cards. Use 4:3 + Contain for all three Hamonshū images.

The colors are already in the artwork. Atmosphere uses amber #fcc553, white 0.66 pt outlines, and 100 radiation-opacity bands. Keep the source colors, including the distinct orbital vendors, by leaving WordPress’s duotone/image filters unset.

5. Preview, then save the page

Preview both desktop and phone layouts. Compare the order with the reference: thirteen images, ten legend links, three review links, two observer panoramas, and both attribution paragraphs. Check that each image opens its matching larger version and that all four Atmosphere/Temperature captions and legends say H3r5.

Confirm the three original lists and the “Two atlases, one shared table” section are still present. When the result is ready, use the page editor’s Save / Update action and inspect the public page. The installed theme determines final typography and spacing. WordPress editor reference.

This package was checked locally. The site’s installed editor version and theme were not accessed during packaging; control labels can vary. The offline preview is a placement reference, not a replacement for the existing page.
