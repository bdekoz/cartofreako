# Setouchi all-sky source for MSP color studies

These compressed SVGs preserve the existing Setouchi ST2 world all-sky map
and its separate legend/bibliography. They are the source artwork for the
four MSP speculation 5 astronomy plates. The pinned calculation instant is
**29 October 2026, 20:00 UTC**, as recorded in the map metadata and legend.

The source has 500 stars, 158 exoplanet hosts, 11 curated deep-sky objects,
the Sun and Moon, seven planets, four asteroids and three comets, with 35
visible labels. Object identifiers, celestial coordinates, colors and source
URLs remain embedded in the SVG. This is a bounded catalog selection.

`provenance.json` records the original local source paths, SVG and archive
checksums, framing receipt, astronomy profile, and the existing source
bibliography. The builder reads these pinned files directly; the original
local Setouchi export directory is not required to rebuild the color studies.

The MSP presentation keeps the original symbol/reference colors and label
positions, sets the sky labels to 12 physical points, changes the ground to
each Randoma11y pair's dark member, and uses the light member for typography.
The existing 43.5-inch image and +4.35-inch
printed horizontal move are retained without applying the frame twice.

Source credits: ESA/Gaia/DPAC; NASA Exoplanet Archive; NASA/JPL; and the
individual providers credited in the curated source attributes. The companion
legend retains the complete source acknowledgments and URLs. Cartography:
Cartofreako, using the AuthaGraph formulation credited to Hajime Narukawa.
