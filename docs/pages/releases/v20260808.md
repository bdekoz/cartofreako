## What changed since `v20260807`

- Generated output is projection-first under
  `assets.generated/<projection>/{svg,pdf,png,thumbnail}/`; all six projections
  now have the same 31-pass thumbnail grid, 186 previews total.
- Star-X uses a fixed `60°S` Antarctic split, preserves source-radius and
  uncut-quadrant Y placement for the unified continent, paints that cap above
  all ordinary quadrant paths, and restores the final black polar star on
  water maps.
- Astronomy separates ground-multiband and Hubble observer products. Planet
  display glyphs are doubled while dotted outlines retain true apparent size.
- Resource and Anthropocene marks use 30% opacity with larger titles. The 14
  standard resource metrics include wind, nuclear, petrochemical, fisheries,
  reefs, and population-over-60 products; the metric catalog visibly separates
  standard, optional, and exploration-only work.
- Network-infrastructure and network-swarm data marks are enlarged over a
  WCAG-oriented light-gray ground.
- Fiber Synthesized becomes a standard default pass from the checked cleanup
  and union of the 2022 and 20260805 submarine-cable snapshots, with the later
  snapshot as the default layer.
- Bathymetry Roulette now starts every form at cycloid `d/r = 1`, increases
  form density with depth through Voronoi groups, uses blue-hue variation, and
  renders at 30% opacity. Bathymetry Hamonshū adds a parallel standard pass
  using Izzi wave curves.
- External authorization persists only successfully completed optional
  workflows. JAXA uses the newest available H09 CLP observation not after the
  run time and records its actual source date.
- Cloud-atmosphere retains its background layer but emits it hidden by default
  with an explicit visibility marker.

The complete implementation record is in
[Stage 13 generation convergence](../../development/stage-13.md).

## Hardware requirements and render host

Downloading and viewing the archive does not require the render workstation.
Use a platform with XZ and tar support and retain enough free storage for the
download, extracted payload, and temporary verification copy. Individual PNG
viewing has ordinary desktop requirements; editing the largest SVG or PDF can
require substantially more memory.

The CPU instruction set and integrated GPU are provenance, not requirements.
The build uses portable C++20 and does not enable `-march=native`. A 128
GB-class host is the release-parity recommendation; lower-memory systems
should use `make assets-single` or `make ASSET_JOBS=1 assets-resilient` and
record their measured host.
