## What changed since `v20260806`

- Resources Stage 12 expands the catalogue to 14 independent products and 84
  six-projection maps. Energy adds wind, nuclear, and petroleum-refinery
  throughput; fauna adds fisheries production and an actual WRI coral-reef
  threat field; human resources add population 60+, two education-attainment
  products, and resident patent applications per million beside population
  under 30.
- Default Anthropocene generation now produces both the 2025 and 2026 NOAA CPC
  temperature fields. The earlier source-separated observation atlas remains
  available through explicit `generate-anthropocene-atlas*` targets.
- `make authorize-external` verifies the local authorization boundary for
  optional JAXA P-Tree, NASA FIRMS, and licensed network-topology passes without
  accepting provider terms or generating an artifact.
- The new Cahill-Keyes snapshot documents every standard pass with 28 real
  480-pixel-wide thumbnails linked to the full layered SVGs.
- Star-X Natural Earth compositing paints transformed Antarctic land,
  coastline, and ice-shelf fragments after ordinary quadrant paths, preventing
  the unified cap from being clipped by later features.
- The release path now preserves the 480-pixel thumbnail contract when
  `assets-single` or `assets-resilient` forwards the 3840-pixel full-size PNG
  setting. The earlier `v20260806` announcement also no longer repeats its
  title inside its notes body.

The source range contains six commits and changes 32 files relative to
`v20260806`. The Stage 12 overview, resource implementation notes, external
authorization boundary, generation guide, and Cahill-Keyes snapshot in the
repository provide the detailed data and interpretation contracts.

## Verify and install

From a directory containing the downloaded asset:

```sh
printf '%s  %s\n' \
  dc1d761def31d77a05a7cc42f9bc0705ee864046f2e235f50c701c9c42fe960a \
  assets.generated.v12.tar.xz | sha256sum --check -
xz --test assets.generated.v12.tar.xz
tar --list --file=assets.generated.v12.tar.xz | sed -n '1,20p'
tar --extract --xz --file=assets.generated.v12.tar.xz
```

Extract from the repository root to install the companion tree at
`assets.generated/`. Use a clean destination when preserving local generated
work; tar extraction can replace same-named files.

## Public extracted-tree mirror

The generated tree is also published for direct browser use beneath the
immutable Berkeley S3 prefix `cartofreako/v12/`. The mirror contains the whole
rendered dataset in a 589-file delivery tree, the original XZ recovery package,
a same-origin SVG viewer, a stored-byte SHA-256 manifest, a release README, and
a last-written `release.json` completion marker. The grid embeds the 28
existing PNG thumbnails. All 187 full SVGs are published only as explicit
`.svg.gz` objects; selecting a thumbnail opens the viewer, which streams and
decompresses the selected SVG in the browser.

See the [S3 v12 publication notes](s3-v12.md) for object layout, exact public
base URL, content metadata, credential handling, immutable upload guards, and
verification procedure. Those notes also record the generated Devastation
Pacific Active Archive report, its PDF verification and digest, and successful
