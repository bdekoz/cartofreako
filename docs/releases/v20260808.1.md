  SVG, PDF, full PNG, and thumbnail form, using `v3.20260805` as the default
  visible snapshot.
- The strict JAXA workflow authorized P-Tree, selected Himawari-9 CLP source
  interval `2026-08-08T04:30:00Z`–`04:40:00Z`, prepared and verified 38,306 H3
  resolution-3 cells, rendered all six projections, and atomically recorded
  `jaxa-ptree` only after success.
- Every Cloud-atmosphere SVG retains exactly one
  `cloud-atmosphere-background` group with `display:none` and
  `data-default-visible="false"`; the hidden layer is absent from PNG export.
- NASA FIRMS remains an unpromoted acquisition/review workflow and therefore
  contributes no release layer. Licensed network topology is not part of this
  release.
- Release builders require exactly one Cloud-atmosphere and one Fiber
  Synthesized object in every projection and every browser-facing format; raw
  counts alone can no longer admit an incomplete package.

All other Stage 13 behavior is unchanged: Star-X uses its fixed `60°S`
Antarctic split and topmost unified cap; astronomy separates ground and Hubble
observers; resource and Anthropocene marks use the revised sizing and opacity;
the standard resource catalog includes wind, nuclear, petrochemical,
fisheries, reefs, and over-60 products; and both revised bathymetry art passes
are present. See [Stage 13 generation convergence](../converge-generation-13.md)
for the complete implementation record.

## Hardware requirements and render host

Downloading and viewing the archive does not require the render workstation.
Use a platform with XZ and tar support and enough free storage for the archive,
extracted payload, and a temporary verification copy. Editing the largest SVG
or PDF can require substantially more memory than viewing a preview PNG.

| Component | Recorded configuration |

| CPU identity | AMD family 26, model 112, stepping 0; microcode `0xb700037` |
| Sampled CPU frequency | 2000 MHz reported by `/proc/cpuinfo` |
| Memory | 131,150,248 kB kernel-visible (about 125.1 GiB) |

The CPU instruction set and integrated GPU are provenance, not requirements.
The build uses portable C++20 and does not enable `-march=native`. A 128
GB-class host is the release-parity recommendation; lower-memory systems
should use `make assets-single` or `make ASSET_JOBS=1 assets-resilient` and
record their measured host.
