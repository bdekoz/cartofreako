## What changed since `v20260805`

- Stage 10 adds one projection-neutral WebAssembly runtime for all six
  projections, topology-aware paths and slices, workers, SVG/Canvas/D3
  adapters, Node checks, and a real-browser smoke path.
- Stage 6b replaces the historical resource interpretation with five current,
  independently defined resource families and 30 non-sparse, six-projection
  products.
- Stage 8b adds separate complete-2025 and partial-2026 NOAA CPC temperature
  fields across all projections while preserving the original source-separated
  Anthropocene observation atlas.
- Cahill-Keyes and Star-X gain edge-folding and seam-routing corrections;
  Myriahedral generation gains reusable perspective layouts and revised
  numerical handling.
- Network-infrastructure sources and pins are tightened, including the
  submarine-cable map source correction.
- `assets-resilient` now runs a bounded, keep-going first pass and a serial
  completion pass. Inkscape PDF and PNG exports write nonempty temporary files
  and rename them atomically, with failed temporary outputs removable through
  `make clean-failed-generated`.

The source range contains 11 commits and changes 107 files relative to
`v20260805`. See the Stage 10, resources, Anthropocene, and generation notes in
the repository for the detailed API, data, and interpretation contracts.

## Hardware requirements and render host

Downloading and viewing the archive does not require the render workstation.
Any platform with XZ and tar support can verify or extract it. Keep at least
3.0 GB free when retaining both the 846 MB download and the 2.153 GB extracted
payload; 4 GB gives useful filesystem and verification headroom. Viewing an
individual 3840-pixel PNG has ordinary desktop requirements. Editing the
largest SVG or PDF can require substantially more memory than viewing its PNG.

The host reports AVX2 and AVX-512 features, but they are not release
requirements. The default native build uses `-std=c++20` and does not enable
`-march=native`; generation is intended to run on any 64-bit processor
supported by the documented compiler, GDAL/GEOS/H3, and Inkscape stack.
Additional cores reduce compile and generator latency but are not consumed
aggressively by the default two-job asset target.

No numeric minimum RAM below the reference host has been release-qualified.
The largest explicit SVG is 118 MB and Inkscape's working set is much larger
than the input file, so release-parity regeneration should use a 128 GB-class
host or establish a separately measured lower-memory baseline. On smaller
machines, use `make assets-single` or `make ASSET_JOBS=1 assets-resilient` to
prevent concurrent generator/export peaks. Reserve at least 4 GB beyond the
source checkout for the generated tree and atomic export temporaries; retain
another 0.85 GB if packaging the XZ archive in the same workspace.

The software and input requirements remain authoritative in the tagged
[`docs/prerequisites.md`](https://github.com/bdekoz/cartofreako/blob/cfe1f8ff15feadec8f3a0c88a9d66648040e61dd/docs/prerequisites.md).

the standard graph also needs the pinned Natural Earth data and cloud/CDN

## Verify and install

From a directory containing the downloaded asset:

```sh
printf '%s  %s\n' \
  5256927f2ac7702d35b1450a45d8bca69b47dc2e9e13b2def1160231e5b8705a \
  assets.generated.v10.tar.xz | sha256sum --check -
xz --test assets.generated.v10.tar.xz
tar --list --file=assets.generated.v10.tar.xz | sed -n '1,20p'
tar --extract --xz --file=assets.generated.v10.tar.xz
```

Extract from the repository root to put the companion tree at
`assets.generated/`. Use a clean destination when preserving local generated
work; tar extraction can replace same-named files.

The source-only checkout does not contain the release bundle. At this commit,
`make check` includes `check-resources-svg-archives`, which expects the 30
resource `.svg.gz` files under `assets.generated/svg/`. Download and extract
the release asset before running the complete check suite, or regenerate the
asset graph locally.
