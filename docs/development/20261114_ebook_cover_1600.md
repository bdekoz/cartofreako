# Corrected ebook upload covers

The original 1400 x 2240 external ebook covers were undersized. Both current
v4 editions now have **1600 x 2560 RGB JPEG** upload covers with 350 dpi
metadata, rendered again from their original artwork and font sources.

| Book | Upload cover | Matching revised EPUB |
| --- | --- | --- |
| World Atlas | [JPEG](../../output/atlas-optional-v4-spread/atlas-world.20261112.v4.ebook-cover.1600.jpg) | [EPUB](../../output/atlas-optional-v4-spread/atlas-world.20261112.v4.cover1600.epub) |
| Starlink Star Light | [JPEG](../../output/atlas-optional-v4-spread/starlink-star-light.v4.ebook-cover.1600.jpg) | [EPUB](../../output/atlas-optional-v4-spread/starlink-star-light.v4.cover1600.epub) |

IngramSpark's file guide requires an external RGB JPEG with at least 1600
pixels on the short side and 1873 on the long side. Its separate EPUB rule
limits each embedded image to 3.2 million pixels. A 1600 x 2560 upload JPEG
contains 4.096 million pixels, so it needs a smaller proportional copy when
embedded. The corrected EPUBs use 1414 x 2262 cover images (3,198,468 pixels).
[IngramSpark file guide, p. 6](https://www.ingramspark.com/hubfs/downloads/file-creation-guide.pdf).

The external dimensions also match KDP's ideal 1600 x 2560 cover size.
This is distinct from KDP's smaller absolute minimum and from the EPUB
interior image limit. [KDP ebook cover specifications](https://kdp.amazon.com/en_US/help/topic/G200645690).

## Production and verification

Izzi owns `scripts/export-ebook-cover.py` and the dated
`config/publication/ebook-cover-20261114.json` profile. The tool checks the
original publication receipt, EPUB and manifest hashes, verifies source
assets, and reuses the existing cover layout/raster renderer at the larger
size. A lossless intermediate avoids enlarging or recompressing the old JPEG.

The revised EPUB differs only in `EPUB/cover.jpg` and its package modification
timestamp. All chapters, map images, legends, sources, navigation and other
resources are byte-identical to the corresponding source EPUB. Both revised
archives pass EPUBCheck 5.4.0 with zero errors or warnings. Actual JPEG and
embedded-image dimensions/color modes were checked, and both external cover
renders were visually inspected. The
[compact validation record](20261114_ebook_cover_1600.validation.json)
records output hashes and checks.

From the Cartofreako root:

```sh
make publication-ebook-covers-v4
```

The main `make publication-editions-v4` target also runs this step. Its
`--resume` mode checks inputs, tool/profile hashes and corrected outputs.
Old print/EPUB build receipts and their artifacts remain unchanged;
`validation/*.cover1600.json` receipts identify the corrected digital outputs.
Exact exporter/profile snapshots are in `sources/ebook-cover-tools/`.

Earlier portrait/landscape deliveries remain historical. To make a corrected
digital derivative for another frozen edition, invoke the same Izzi exporter
with that edition's receipt and manifest. The separate typographic print
cover PDF retains its physical page dimensions; pixel-width requirements
apply to the ebook JPEG upload, not that vector print artwork.
